# 🤖 Friendly AI Bot

A simple and interactive AI chatbot built using **Python, Streamlit, and Ollama**.

## ✨ Features

- 🤖 AI-powered chatbot
- 💬 Ask questions and get answers
- 🧠 Uses Llama 3.2 model
- 🎨 Attractive and responsive Streamlit UI
- ⚡ Fast local AI responses
- 😊 Friendly and simple explanations

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2

Install the required Python packages:

pip install streamlit ollama
